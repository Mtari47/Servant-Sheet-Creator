Servant Sheet Creator

Generate Fate/Grand Order-style servant sheets. Web app (Flask) and offline desktop (PySide6) versions.

View on GitHub Quick Start

About

This site hosts static information for the project. The interactive generator is a Flask application and cannot run on GitHub Pages directly. Use the repository to run locally or the packaged desktop version.

Run Locally (Web)

  1. Install Python 3.9+.
  2. Create and activate a virtual environment.
  3. Install requirements: pip install -r requirements.txt.
  4. Start: python app.py, then open http://127.0.0.1:5000/.

Offline Desktop (Windows)

A PySide6 desktop UI is included under offline/. Launch with:

python -m offline.offline_main

Export to PNG/PDF is available in the desktop app.

Features

  • FGO Mode toggle with stats, hits, and card list image.
  • Dynamic skill and NP scaling tables; NP Type support.
  • Scroll-friendly modals for tall content.
  • Export to PNG/JPEG/PDF on the web; PNG/PDF offline.
